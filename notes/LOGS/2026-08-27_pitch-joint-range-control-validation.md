# 2026-08-27 第5関節 pitch の可動範囲と追従安定性

## Topic
第5関節 pitch の ±45°制約が、現在の関節空間 LQR に必要な安定性要件かを検証した。

## Summary
ユーザー環境の通常の `main.py -> Simulator.run()` 経路で、pitch を 0→−180°→+180°と動かす追従試験を実施した。
pitch 単独試験と他の5関節も同時に動かす試験は、いずれも ±90°の運動学的特異姿勢を通過して正常終了した。
計測を追加した pitch 単独試験の最大追従誤差は 0.00406 rad であり、発散、NaN、Inf はなかった。
したがって、現在の ±45°制約を関節空間 LQR の安定性要件または特異姿勢回避要件として維持する根拠はない。
設定値は実機の可動範囲へ置き換えるべきであり、モデル上で pitch を ±180°まで含む単一軌道を追従できることを確認した。

## History
既存の励起軌道設定では、人の数え方で第5関節に当たる pitch が `q_min/q_max=±π/4` に制限されていた。
過去の TODO は、球面手首の角速度 Jacobian が pitch=±π/2 で特異になることを根拠に、この制限を安全余裕として維持していた。
一方、現在の制御器は関節空間 LQR であり、task Jacobian の逆行列を計算しない。
そのため、運動学的特異姿勢の通過と関節空間制御の発散は同一ではない。
設定ファイルに残る「pitch=0 を横切ると LQR が発散する」という趣旨のコメントも、特異点の位置と矛盾している。

最初の簡易試験は隔離環境で実行したため、正式な採否根拠から除外した。
正式試験はユーザー環境の X11 と通常のレンダリング経路を使い、目標 60 Hz、物理刻み 2 ms、実測準拠の制御ノイズ、seed 42、`--no-get-unperturbed` で実行した。
軌道長は 36.35 s、目標は 2181 frame、物理計算は 18175 step とした。
pitch の目標軌道は 0→−π→+π、最大速度は 0.5 rad/s とした。
通常の `main.py` 経路による試験は終了コード 0 で完了した。
同条件の計測付き再試験では、制御時と記録時の最大 pitch 誤差はいずれも 0.0040603 rad、記録時の RMS 誤差は 0.0023341 rad だった。
`min(abs(cos(pitch)))=5.61e-5` であり、±90°の特異姿勢を極めて近く通過していた。
最終 pitch は 3.1415926 rad であり、全区間で発散、NaN、Inf はなかった。
追従結果は [単独試験の図](../figures/2026-08-27_pitch_pm180_tracking_qpos.png) に保存した。

pitch だけが動く条件に限定された結論を避けるため、他の5関節へ窓付き正弦波を加えた試験も実施した。
以下の6要素はいずれも j1 から j6 の順である。
6関節の目標最大絶対角度は `[0.1492, 0.1159, 0.0998, 0.6729, 3.1416, 0.9987]` rad だった。
目標最大絶対速度は `[0.0913, 0.0980, 0.1054, 0.4829, 0.5000, 0.8599]` rad/s だった。
目標最大絶対加速度は `[0.0626, 0.0807, 0.1164, 0.3413, 0.1307, 0.7971]` rad/s² だった。
多関節試験も通常の `main.py` 経路で終了コード 0 となり、発散せずに完了した。
追従結果は [多関節試験の図](../figures/2026-08-27_pitch_pm180_multijoint_tracking_qpos.png) に保存した。

今回の多関節軌道は低加速度の手設計軌道であり、最終的に採用する最適化済み励起軌道ではない。
また、モデルには関節位置限界とアクチュエータ飽和が設定されていない。
したがって、今回の結果は現行シミュレーションと関節空間 LQR の数値的な追従安定性を示すが、実機の安全性や可動範囲を保証しない。
試験中に得た OLS/TLS 数値も、可動範囲の安定性確認用軌道から得た値であるため、励起方式の採否根拠には用いない。

試験準備中、`duration * fps` が整数でない場合に目標 frame が先に尽き、`Simulator.run()` が `IndexError` になる問題も確認した。
原因は目標列の生成が `int(duration * fps)` で切り捨てる一方、記録判定が境界 frame を要求することにある。
正式試験では軌道長を 60 Hz の frame 境界へ合わせて回避したが、実装上の問題は未修正である。

## Decisions
- 第5関節 pitch の ±45°制約を関節空間 LQR の安定性要件として扱わず、実機可動範囲へ置き換える / 却下: ±45°を特異姿勢回避の安全余裕として維持する — エージェント判断

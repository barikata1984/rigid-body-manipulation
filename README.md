## Running Tests

To run all tests in the project, navigate to the project root directory and execute the following command:

```bash
pytest
```

This command will automatically discover and execute all test files (e.g., `test_*.py`) located in the `tests/` directory. The test results, including successes, failures, and any errors, will be displayed in your console.

## Analyzing Simulation Errors

To analyze the errors from simulation data, use the `calculate_errors.py` script. This script takes the path to a CSV data file as a command-line argument.

```bash
python calculate_errors.py --file-path <path_to_csv_file>
```

Replace `<path_to_csv_file>` with the absolute path to the CSV file generated by a simulation run (e.g., `debug_log/dev-jointpos_limits/data/data_YYYYMMDD_HHMMSS.csv`). The script will output Max Absolute Errors and RMSE Errors for position, velocity, and acceleration for all joints.
